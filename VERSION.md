# v4.9 — Modes & Collection

Published build of the Four Color Map Game prototype.

- Standard/thoughtful mode: limited-use bonus color and six consumable skills
- Quick tutorial mode: no bonus color and three loaned skills
- Curse backlash for Color Seal
- Half-cell Shift changed to ★4
- Consumable skill inventory and cosmetic coin economy
- 7-correct quiz consolation reward
- Full-paint trophies and cosmetic-only achievements

The browser entry point is `index.html`. The payload reconstructs the exact tested single-HTML build and verifies its SHA-256 before launch when Web Crypto is available.
