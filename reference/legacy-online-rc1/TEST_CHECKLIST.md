# 実Supabase・2端末受入テスト

## 事前条件

- [ ] Supabaseの匿名ログインが有効
- [ ] `supabase/001_online_rooms.sql` をSQL Editorで実行済み
- [ ] `index.html` と `online-config.js` を同じ公開先へ配置済み
- [ ] 端末Aと端末Bで同じURLを開ける
- [ ] 2端末が異なる匿名ユーザーになるよう、別端末または別ブラウザプロファイルを使う

## 接続

- [ ] 端末Aでオンライン対戦を選択できる
- [ ] 端末Aで8文字以上の合言葉を使ってルームを作成できる
- [ ] 待機画面に合言葉、コピー、退出ボタンが表示される
- [ ] 端末Bで同じ合言葉を入力し参加できる
- [ ] AがPlayer A、BがPlayer Bとして表示される
- [ ] 両端末で「接続中」または「Realtime接続中」と表示される

## 手番・秘密情報

- [ ] Aの手番中、BではAの持ち色と持込カードが表示されない
- [ ] Aの手番中、Bは盤面を操作できない
- [ ] Aが初回エリアを指定すると、Bへ数秒以内に反映される
- [ ] Bの手番開始ボタンを押すまでB自身の秘密情報が隠れている
- [ ] Bが合法色で彩色するとAへ反映される
- [ ] Bが次のエリアを指定するとAへ手番が戻る
- [ ] 公開ログが両端末で一致する

## スキル

- [ ] 彩色前スキルを1種類使用し、相手端末へ結果が同期される
- [ ] 工作スキルを1種類使用し、盤面形状が同期される
- [ ] 熟考モードで正常発動したカードだけ、使用者端末の在庫が1枚減る
- [ ] キャンセルしたカード操作では在庫が減らない
- [ ] 相手の持込カード一覧は相手手番中も表示されない

## 再接続・競合

- [ ] 手番待ち側のページを再読込みして同じ席へ復帰できる
- [ ] 手番側のページを再読込みして同じ席へ復帰できる
- [ ] 一時的に通信を切り、復旧後に盤面が再同期される
- [ ] 同じ端末で二重タブ操作しても古いversionが新状態を上書きしない
- [ ] 片方が退出すると相手側に終了状態が反映される

## 終局・再戦

- [ ] 投了が相手端末へ反映される
- [ ] 勝者のローカル勝利数が1回だけ増える
- [ ] 作成者だけが「同じ構成で再戦」を実行できる
- [ ] 再戦後、盤面と公開ログが両端末で初期化される

## セキュリティ確認

- [ ] 未参加の第3ブラウザからルーム行を直接SELECTできない
- [ ] `anon`／`authenticated`からテーブルへ直接INSERT・UPDATE・DELETEできない
- [ ] 相手手番で`fc_submit_state`を呼ぶと`not_your_turn`になる
- [ ] 古いversionで`fc_submit_state`を呼ぶと`version_conflict`になる
