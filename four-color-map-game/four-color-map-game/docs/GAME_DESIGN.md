# Game Design Specification v0.1

## 1. Purpose

四角形グリッド上でプレイヤーが交互に地図を構築し、相手へ彩色対象を押し付けるターン制対戦ゲームを定義する。

四色定理をモチーフとするが、過去の彩色を自由に塗り直せない逐次ゲームであるため、「4色あれば常に現在の状態から合法手がある」とは限らない。その詰みを対戦要素として利用する。

## 2. Core concepts

### Cell

盤面の最小単位。未使用セルは新規エリア指定可能／不可の状態を持つ。

### Region

1個以上のセルからなる領域。通常の新規エリアは辺接続で連結していなければならない。

### Adjacency

通常時は正の長さを持つ辺を共有するエリアのみ隣接。点接触は無視する。

### Palette

各プレイヤーの現在使用可能色集合。初期案は全5色程度、各プレイヤー3色。相手には原則非公開。

## 3. Region creation

新規エリアは以下をすべて満たす。

1. 未使用セルのみ。
2. `canCreateRegion = true` のセルのみ。
3. 現在の最大指定セル数以下。
4. 選択セルが4近傍で連結。
5. 初手以外は既存エリアの少なくとも1つへ辺接触。

## 4. Turn flow

### First turn

先攻は最初の未彩色エリアを指定し、相手へ渡す。

### Normal turn

1. 相手から受け取ったpending regionについて、必要なら彩色前スキルを使用。
2. 合法色を算出。
3. 合法色から1色を選び、エリア全体を単色で彩色。
4. 必要なら工作系スキルを使用。
5. 次に相手が彩色する新規エリアを指定。
6. 相手へ手番を渡す。

Region Splitを使用した場合は例外で、返送側エリアが5の新規指定を兼ねる。

## 5. Coloring

`PlayableColors = Palette - AdjacentColors`

隣接色はdistinct集合として扱う。

## 6. Loss

合法色0になった時点では即敗北しない。彩色前に使用可能なスキルを任意枚数使用できる。

スキル使用後も合法色0なら敗北。

## 7. Map completion victory

正常に彩色した後、合法な新規エリアを1つも作成できなければ、そのプレイヤーの完塗り勝利。

## 8. Hidden information

- 初期持ち色：相手に非公開。
- 使用した色：盤面から公開情報になる。
- Palette Change後の新色：非公開。
- 持込スキルカード：原則非公開。使用時に公開される想定。

## 9. Same-color merge

盤面変形または既塗エリア色変更により別Regionの同色エリアが辺接触した場合、同一連結成分を1 Regionへ統合する案を採用する。

新規エリアセル上限は作成時のみに適用し、合体後に上限超過してもよい。

## 10. Shift rule

初回使用時に発動者がROWまたはCOLUMNを選択し、試合中のシフト軸を固定する。

ROW固定後は各使用時に左/右0.5セルを選択可能。COLUMN固定後は上/下0.5セルを選択可能。

## 11. Playable-area resize

縮小はセル削除ではない。未使用セルの `canCreateRegion` をfalseへ変更し、将来の新規エリア候補から除外する。既存Regionには影響しない。

## 12. Quiz and gacha

初期設定：

- 10問/チャレンジ
- 3問目の誤答で失敗
- 通常クリア 1回
- 5問連続正解 5連
- 10問全問正解 10連
- 最高報酬のみ適用
- 難易度がガチャ排出重みを決定
- 低難易度でも★5確率 > 0

## 13. Non-goals for first prototype

- 課金
- 広告
- オンライン対戦
- 本番認証
- ランキング
- チート対策
- 高度なCPU

## 14. Unresolved / balance parameters

- 正式ゲーム名
- 盤面サイズ
- 新規エリア最大セル数
- 全体色数、初期持ち色数
- 持込カード枚数
- カードごとのレアリティ・排出率
- スキル効果量、持続時間、対象範囲
- 同色合体の正式確定（現在は推奨仕様）
- オンライン時の制限時間・切断扱い
