# Standard クイズ「解いて楽しい」改善契約

## ねらい

問題数や装飾を増やすだけでなく、各問で「何を考えるか」がすぐ分かり、回答直後に小さな発見があり、連続正解が次の一問への期待につながる体験にする。

## 守る既存契約

- 1セット10問、難易度は Lv.1〜Lv.5、報酬判定はサーバー側のままにする。
- 問題別タイマー、1問1回の短時間ヒント、ヒント表示中の時計停止を維持する。
- ヒントは有用な公式1つと無関係な公式2つを混ぜ、正しい公式を特定しない。
- MathML、図形SVG、文章題、`prefers-reduced-motion`、対戦成立時の安全な一時停止・再開を壊さない。
- クイズ正解やストリークは追加報酬を発生させず、既存のガチャ券付与を変更しない。

## 受け入れ条件

### 1. 一目で分かるミッション

- 全問題に、数式とは別の折り返し可能な日本語ミッションを表示する。
- ミッションは「何を求めるか」を明示し、横スクロールしなくても読める。
- 長い数式だけが必要な場合は数式領域のみ横スクロールを許可する。
- 問題形式を「ひらめき計算」「図を読む」「文章を整理」などの短いラベルで示す。

### 2. 難易度は思考段数で伝える

- Lv.1〜2は主に1段階、Lv.3〜4は主に1〜2段階、Lv.5は主に2〜3段階で考える問題にする。
- Lv.5を単純な制限時間短縮で難しくしない。
- 各問に「1段階」「2段階」「3段階」の目安を表示し、難しさの理由を予告する。

### 3. 回答直後の小さな学び

- サーバー確定後の○×表示に、正解値だけでなく一行の解法メモを表示する。
- 解法メモは既存の `explanation` を使い、正解送信前に答えを露出しない。
- 不正解・時間切れでも責める表現を避け、次に試せる考え方を示す。

### 4. 連続正解の盛り上がり

- 直近の連続正解数をローカルの回答結果から計算し、2連続以上で表示する。
- 2〜3連続、4〜5連続、6連続以上で文言と見た目を段階的に変える。
- 再読み込み時もサーバー確定済み回答から復元し、誤答・時間切れで0へ戻す。
- ストリークは演出だけとし、採点や報酬へ影響させない。

### 5. テンポと安全性

- 回答送信中、ヒント表示中、対戦ハンドオフ中は二重回答できない。
- 即時フィードバックは次問を隠さず、キーボード・スクリーンリーダーでも内容が分かる。
- 動きは `prefers-reduced-motion` で停止する。

## 検証

- 静的契約テスト：DOM ID、表示メタデータ、ストリーク計算、解法メモ、reduced-motion。
- 生成器テスト：全Lvで日本語ミッション、問題形式、思考段数を返し、Lv.5の時間を短縮しない。
- ブラウザテスト：390pxでミッションに横あふれがなく、正解→ストリーク上昇、不正解→リセット、再読み込み復元を確認する。
- 既存のクイズ、対戦ハンドオフ、ガチャ報酬テストを回帰実行する。
