双方へ全試作を各1回対称貸与。各操作区間にcolor/area/disruptを各1回まで。cancel/不適格/不合法は状態・version・手札・RNG・保存とも不変。成功は1version・1charge、同じaction IDの再送は二重消費しない。通常の彩色可否を先回りしてUIへ表示しない。盤面と両者の持ち色はこの端末上では公開する（オンラインの秘密状態取得はしない）。

風化/白化は未塗の宙ぶらりん状態を残さず即pendingへ。合流前の形へ復元せず現在形状のみ。現在pending/reserved/予約済み領域と同ターン作成領域は対象外。色交換/反転は領域統合なし、二色領域は色の組を一緒に移す。市松を含むすべての彩色/変更で色集合の交差を辺ごとに検査する。全消去後も空盤面から通常指定を再開できる。

遅延イベントは登録順に、相手の正規彩色が成功した後だけ処理する。誤彩色敗北・投了では発動せず終局時に破棄。対象の形/色スナップショット一致が必要。新しい保存キー `fourColorMapGame.skillWorkshop.v1` のみを利用し、既存save/connection/profileには触れない。読み込みはschema/ruleset/幾何/色集合/charge/RNG/予約を検証、破損データを黙って上書きしない。

試用入口ではカード選択→適した練習盤面→対象選択→実行→普通の彩色/指定まで続けられる。空盤面からの二人練習も用意。CPU判断・通常対戦・経済への統合、全スキル禁止原案、自然対戦のバランス評価、物理端末は今回未実装/未検証と区別する。
