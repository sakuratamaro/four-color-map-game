# 公開画面の日本語整理（2026-11-01）

プロフィール、カード選択、クイズの操作・保存状況、ガチャ券の入手方法、遊び方の説明を整理する。Geminiの33件の編集案を原文と照合し、ゲームの理解に役立つ変更を選んだ。意味が欠けた短縮やボタン名の誤字は採用しない。

## 変更内容

- ニックネームの公開先、各カテゴリ2枚の選択、売却できないカードを短く明示する。
- ガチャ券の入手方法を4段落に分け、直近60分・10試合の制限を対人戦の説明に残す。
- 遊び方の長い段落を分ける。カードのⓘは読むだけ、カード本体は使用ボタンであり、即時発動と対象選択後の発動があることを維持する。
- 色が塗れなくても自動敗北しないこと、同じ色を辺で接するエリアに塗ると負けること、盤面に次のエリアを作れない場合は塗った人が勝つことを維持する。
- クイズの選択肢が停止する操作、メモ中は時間が進むこと、回答の保存待ちを平易に説明する。保存済み・未確定・保存を確認できない状態を区別する。
- ローカル版は全10問・3回目のミスで終了する条件を明示する。古い固定カード数の説明を除き、券でカードを引く案内にする。
