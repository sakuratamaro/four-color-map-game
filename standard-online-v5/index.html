        BEFORE MATCH
        
      
        対戦開始前に取りやめますか？
        
      
        参加者全員の開始前対戦を終了します。戦績・報酬は発生せず、送信済みの6枚や所持カードも消費されません。この操作は元に戻せません。
        
      
        
      
        
        
        
      
        
    
        
          
  
    
        
      
        遊び方
        
      
        相手に塗ってもらうエリアを作り合う、2人の対戦ゲームです。
        
      
          
        
        1. エリアを渡す
          先手は、まずエリアを作ります。表示された数のマスを辺でつなげて選び、「選んだエリアを渡す」で確定します。2つ目からは、すでにあるエリアに接する形で作ります。
          2. 
        
        2. 受け取ったエリアを塗る
          持ち色から1色を選びます。辺で接しているエリアと同じ色を塗ると負けです。角で触れるだけなら同じ色でもかまいません。持ち色は基本2枠と、残り回数つきのおまけ色です。
          3. 
        
        3. 塗ったら、次のエリアを作る
          画面に表示された必要マス数で、次は相手へエリアを渡します。「塗る→作る」を交互に続けます。スキルで手順が変わるときは、盤面近くの案内を確認してください。
          4. 
        
        4. 困ったらスキルも使おう
          対戦には「色・エリア・妨害」から2枚ずつ、6枚のスキルを準備します。効果はカードのⓘで確認でき、読むだけでは消費しません。カード本体は使用ボタンです。押すとすぐ発動するものと、対象を選んでから発動するものがあります。塗れる色がないときも、自動で負けにはなりません。使えるスキルで切り抜けるか、「投了」を選びます。
          5. 
      
        
      
        正しく塗ったあと、盤面に次のエリアを作れる場所がなくなれば、塗った人の勝ちです。
        
      
        対戦は下の「対戦」タブから。説明を読むだけでは、対戦もカードの消費も始まりません。
