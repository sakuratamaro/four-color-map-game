No code license in this repository extends to them. Obtain materials for separate reuse directly from the author's website and follow the author's terms. Do not redistribute these files as a separate asset pack.

Pixel processing: none. The game uses CSS face cropping and proportional full-body fitting; no AI redraw, retouch, recolor or format conversion. Original ZIPs, preview sheets and unused expressions are not included.

The older generated atlas in the parent directory is retained as historical source; it is not the active v3 CPU artwork.
